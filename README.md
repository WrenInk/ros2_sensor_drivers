# ROS 2 传感器驱动集合

本仓库用于集中管理各类 ROS 2 传感器驱动，每个传感器驱动维护在各自独立的分支中。

## 克隆传感器驱动与相关文档

***使用说明：*** *点击传感器名称旁的「link」可跳转至对应驱动分支，查看分支内的 `README.md` 及操作文档。*

***克隆方式：*** *复制对应传感器的命令到终端执行即可克隆该分支（请将 `<REPO_URL>` 替换为本仓库实际地址）。*

### Mid-360 [link](../../tree/mid360)

Linux/Mac: `git clone -b mid360 <REPO_URL>`

Windows: `git clone --branch mid360 <REPO_URL>`

### STP-23L [link](../../tree/stp23l)

Linux/Mac: `git clone -b stp23l <REPO_URL>`

Windows: `git clone --branch stp23l <REPO_URL>`

### WLR-716 [link](../../tree/wlr716)

Linux/Mac: `git clone -b wlr716 <REPO_URL>`

Windows: `git clone --branch wlr716 <REPO_URL>`

### Lslidar_N10 [link](../../tree/lslidar_N10)

Linux/Mac: `git clone -b lslidar_N10 <REPO_URL>`

Windows: `git clone --branch lslidar_N10 <REPO_URL>`
