# ROS 2 传感器驱动集合（ros2_sensor_drivers）

本仓库用于集中管理各类 ROS 2 传感器驱动，每个传感器驱动维护在各自独立的分支中。

## 克隆传感器驱动与相关文档

***使用说明：*** *点击传感器名称旁的「link」可跳转至对应驱动分支，查看分支内的 `README.md` 及操作文档。*

***克隆方式：*** *复制对应传感器的命令到终端执行即可单独克隆该驱动分支。*

### Mid-360 [link](https://github.com/WrenInk/ros2_sensor_drivers/tree/mid360)

Linux/Mac: `git clone -b mid360 https://github.com/WrenInk/ros2_sensor_drivers.git`

Windows: `git clone --branch mid360 https://github.com/WrenInk/ros2_sensor_drivers.git`
